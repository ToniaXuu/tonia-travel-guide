v3.1.0 最新 2026-09-21

全站统一左栏 · 双主题 · 交互粒子

这一版不是只改大连页——左侧导航、深浅色双主题、交互粒子背景、首屏加载动效四个模块已抽成全站共享资产，主页、版本更新、烟台、淄博、大连、住宿页全部接入，并顺手把大连行程调整为玩满三天。

  • 新增全站通用化：把左侧栏 / 主题 / 粒子 / 加载动效抽成共享资产 assets/ui-init.js、assets/ui.css、assets/ui.js，6 个页面统一引用，不再各写一份
  • 新增没有多方案页签的页面（主页 / 版本更新 / 烟台 / 淄博 / 住宿）自动切换为章节锚点导航：点击平滑滚动 + 随滚动高亮当前章节，左栏外观与大连页完全一致
  • 新增方案切换器从顶部横排改为左侧常驻竖排导航（268px sticky），窄屏自动回落为顶部横条 + 浮动主题按钮
  • 新增深色 / 浅色双主题，四种模式：手动浅色、手动深色、按自定义时段自动切换（支持跨零点）、跟随系统实时联动
  • 新增主题偏好在 CSS 之前预置应用（零闪白/闪黑），并存 localStorage，多标签页之间自动同步
  • 新增重写增强版粒子背景：Canvas 全屏、鼠标引力排斥 + 光标光晕 + 悬停连线 + 点击涟漪与冲击波，粒子数量按视口面积自适应、切后台自动暂停
  • 新增首屏加载动效：双层旋转弧 + 百分比进度 + 分阶段文案，等地图就绪或 3.2s 兜底自动淡出
  • 优化共享资产只提供结构与变量，各页保留自己的色彩气质：主页/版本更新暖白、烟台冷蓝、淄博暖橙、大连蓝调，只覆盖 :root 变量即可
  • 新增方案 A 行程重排：10/02 - 10/05 四天，大连玩满三个整天（新增金石滩一日：滨海国家地质公园 + 十里黄金海岸），10/04 22:50 夜航，10/05 08:30 高铁返济南
  • 优化夜航改走「金石滩 → 地铁 3 号线大连湾站 → 打车 3km 到港」，全程轨道、避开市区晚高峰，比原方案打车 20km 稳得多
  • 优化返程由 K286 夜车改为 G2010 高铁（3h49m、¥198），10/05 12:19 就到济南站，还多出 10/06 一整天假期；两人总预算 ¥4,996 → ¥4,806
  • 修复核对渤海轮渡时刻表：22:50 大连湾新港发船的班次是「渤海玛珠」、05:30 抵烟台港客运站，原稿写的「渤海翠珠 05:50 到」船名与到港时间都不对
  • 修复flex 外壳下内容区被宽表格撑开导致 banner 右侧被裁——给内容区加 min-width:0，宽表格改为卡片内横向滚动
  • 修复矮屏下左侧栏方案卡片被 flex 压扁并裁掉文字（改为 flex:0 0 auto + 容器滚动）
  • 修复移动端主题面板定位失效——父级 backdrop-filter 会使其成为 fixed 定位的包含块，窄屏下已禁用
  • 修复老页面里写死的浅色内联样式（说明框、表格底纹）在深色下依然刺眼——用属性子串选择器统一兜底，不改动历史标记
  • 修复左栏占用 268px 后原有 @media 断点全部失效导致横向溢出，断点统一后移到 1240px 并逐宽度复测 430 / 768 / 1024 / 1280 / 1440
